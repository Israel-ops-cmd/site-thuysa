# Site Thuysa Andrielly | Terapeuta Ocupacional

Landing page estática (HTML, CSS e JS puros, sem build). Pronta para Vercel: importe o repositório, framework "Other", sem comando de build.

Pendências marcadas com `[PENDENTE]` no index.html: horários, anos de formada, números de atendimento (bloco `.numeros` com `hidden`), depoimentos, logo e fotos originais, domínio definitivo (canonical, og:url, sitemap, robots).
